# Motion Manga Lab

A public, mobile-first experiment for validating whether subtle motion improves the manga reading experience without disrupting reading pace.

## Development

Requirements:

- Node.js 22.12 or newer
- npm 11 or newer

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm test
npm run typecheck
npm run lint
npm run build
```

The project follows test-driven development: add a failing test for observable behavior before implementing that behavior.
